        Si la page est déjà en mémoire
            Continuer
        Sinon

            Sinon

    Afficher les résultats avec afficher_simulation

        Sinon
            Ajouter un défaut de page
            Si mémoire non pleine
                Ajouter la page
            Sinon
                Remplacer la page la moins récemment utilisée
            Fin Si
        Fin Si

    Afficher les résultats avec afficher_simulation

Définir fonction simuler_seconde_chance(donnees)
    Initialiser variables pour les cadres, historique, défauts de page, bits de référence
    Pour chaque page dans la chaîne de référence
        Si la page est déjà en mémoire
            Mettre à jour son bit de référence
        Sinon
            Ajouter un défaut de page
            Si mémoire non pleine
                Ajouter la page avec bit de référence
            Sinon
                Remplacer la page avec bit de référence 0
            Fin Si
        Fin Si
        Ajouter l'état actuel des cadres et bits de référence à l'historique
    Fin Pour
    Afficher les résultats avec afficher_simulation_seconde_chance
